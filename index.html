Change text on any image

pngn is a free in-browser editor for text that is already part of a picture. Drop a PNG, JPEG, or WebP, select the words, type a replacement, and export. No account. The image never leaves your device.

How to change text on an image

  1. Drop a PNG, JPEG, or WebP, or click to open one from your computer.
  2. Draw a box around the words to change. pngn reads the text and paints the old letters out of the background.
  3. Type the new text. Adjust font, size, color, stroke, and position.
  4. Export a PNG, JPEG, or WebP at the original resolution. The download is built locally.

Edit image text without uploading

Most “edit text in image” tools send the file to a server. pngn does not. OCR, background reconstruction, and export run in this browser.
